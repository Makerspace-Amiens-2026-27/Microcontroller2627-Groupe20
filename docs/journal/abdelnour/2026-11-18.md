# Séance 1 – Préparation de l'environnement de développement

**Objectif de la séance :**

Préparer l'environnement informatique nécessaire au développement et à la programmation de mon microcontrôleur.

### Travail réalisé

Pour commencer mon projet sur le microcontrôleur, j'ai procédé à l'installation de Visual Studio Code (VSCode), qui sera mon environnement de développement.

Ce logiciel me permettra d'écrire, de modifier et d'organiser le code nécessaire au fonctionnement de mon microcontrôleur.

J'ai également identifié les différentes étapes nécessaires à la préparation de mon environnement de travail :

- Installation de Visual Studio Code.
- Installation de l'extension PlatformIO.
- Vérification de la toolchain pour le microcontrôleur ESP32-S3.
- Vérification de la communication avec le microcontrôleur à l'aide du port série et de TelePlot.

### Bilan de la séance

L'installation de Visual Studio Code a été réalisée avec succès. Cette première étape me permet de commencer à préparer mon environnement de développement.

Les prochaines étapes consisteront à installer PlatformIO, à configurer la chaîne de compilation pour l'ESP32-S3 et à vérifier la communication entre l'ordinateur et le microcontrôleur.
